A one-line resignation letter for make.fun's "The One-Line Exit" bounty: a ghostwriter resigns from the author he has ghosted for years — and will, of course, write his own letter of recommendation, in the author's voice, as always. The program writes the single line to /output/entry.txt and validates it against the gate (UTF-8, 1–140 characters, one line).

## Run it

```sh
python3 main.py
```
